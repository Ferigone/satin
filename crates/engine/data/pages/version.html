About Satin

Satin is an open-source web browser with a Rust engine. This Windows x64 alpha has partial website compatibility.

Browsing

  • HTTP and HTTPS, certificate checking, tabs, history, zoom, and a persistent profile.
  • Forms with text fields, choices, a native Windows file picker, and basic validation.
  • Cookies, localStorage, sessionStorage, and basic navigation within a document.
  • Installed copies check for releases on GitHub and apply verified updates at the next launch.

Pages and graphics

  • Incremental HTML parsing, DOM updates, and subsets of CSS Flexbox, Grid, and positioned layout.
  • System and web fonts, images, SVG shapes and paths, and Canvas 2D.
  • Progressive H.264/AAC MP4 playback on Windows, including pause, seek, and volume.
  • Fragmented MP4 through Media Source Extensions on Windows, including separate H.264 video and AAC audio tracks.

JavaScript and web APIs

  • Promises, async functions and generators, modules, classes, BigInt, and typed arrays.
  • Events, timers, MutationObserver, and IntersectionObserver.
  • Fetch, Blob, File, FormData, streams, and message channels within a document.

Compatibility

Complex sites may stop during initialization or render incompletely. YouTube and Twitch playback remain priority gaps. Further media work includes additional codecs, worker-based streaming, and encrypted media.

Further work includes web workers, WebAssembly, Intl, Proxy, IndexedDB, advanced CSS and SVG, accessibility, and content process isolation. Large scripts and documents may hit resource limits.
