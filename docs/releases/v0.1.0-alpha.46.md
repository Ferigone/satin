## Changes

- Classic scripts, modules and workers can run beyond the former instruction allowance under a CPU and elapsed-time watchdog.
- Web compatibility improvements include binary XMLHttpRequest bodies, Fetch cache modes, live `dataset` attributes, contextual HTML ranges and additional DOM events and element interfaces.
- JavaScript preserves evaluation order in long addition chains and grouped assignment method calls. OpenStreetMap's JavaScript fixture covers the grouped assignment fix, and pages can read `devicePixelRatio` during startup.
- CSS supports nested sRGB color mixing. Windows QA covers native tab behavior, favorites scrolling and the offline updater.

## Public video compatibility

Native Windows playback supports progressive H.264/AAC MP4 and segmented Media Source Extensions. YouTube and Twitch playback are still in development. On the alpha.46 media candidate, YouTube decoded a single frame and stayed paused. Twitch reached its player worker, which requires `importScripts`. Continuous playback, audio output and Twitch chat have yet to be verified in Satin.
