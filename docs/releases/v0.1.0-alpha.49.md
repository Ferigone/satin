## Engine migration checkpoint

The source tree includes experimental integrations for html5ever document and
fragment parsing, V8 document scripts, selected CSS declarations through Stylo,
Vello/wgpu page rendering, and progressive MP4 playback through GStreamer.

These integrations are under development and disabled in the Windows x64
release. The installer uses Satin's existing parser, JavaScript VM, CSS engine,
software renderer, and Media Foundation playback. The experimental build
features have incomplete compatibility and have not passed release verification.
