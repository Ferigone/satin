## Windows updater

- **Sprawdź aktualizacje** in the browser menu opens a check even when the update icon is hidden. **Alt+U** opens the same panel.
- Installed copies download the verified update and switch versions only after you choose **Restart and update**.
- Copies launched directly from an extracted folder can detect new releases and open the correct release page. Use the Windows ZIP and run `Install.cmd` to set up the managed installation.
