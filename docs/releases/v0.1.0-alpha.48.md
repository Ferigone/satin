## Native playback and web compatibility

- Improved WebAssembly startup, dedicated-worker APIs, and worker message delivery for media players.
- Fixed seeking during playback in an open MediaSource and resumed video frame presentation as the buffer refills.
- Added document selection backed by DOM ranges, live named attributes, and inert HTML parsing. Dynamic script preparation now counts work that is still pending.
- Fixed empty HTTP POST and PUT framing and sizing of embedded SVGs that specify only an aspect ratio.

Native Windows tests confirmed live Twitch picture and sound and readable public chat in a separate chat window. YouTube tests confirmed picture, sound, pause, resume, and seeking. Slow startup and intermittent YouTube resets were observed during public-site testing.
